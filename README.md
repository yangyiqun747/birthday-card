# 为你点亮一颗星 · 新版

新版沿用原来的 GitHub Pages 地址。开发以此前发布的 `6537b2dc` 为基础，旧版源码随提交历史保留。[打开贺卡](https://yangyiqun747.github.io/birthday-card/) · [更新前的源码](https://github.com/yangyiqun747/birthday-card/tree/6537b2dc2ac3d45e137ce287072df0d6e7b086c8)

## 体验

点亮星空，收下三颗星的短祝愿，原来那座粒子蛋糕便从星尘里聚出来。可以主动点亮蜡烛，也可以等它亮起。许愿没有倒计时。点击画面或「熄灭蜡烛」即可继续，吹气和手势仍可自行启用。熄烛后留一小段烟和静默，烟花过后由收礼者亲手拆信。信纸角落还有一颗可以点的小星星。

原蛋糕的点云几何、颜色、三层轮廓、烛光和 WebGL 着色器继续使用。点云、拖动、缩放不需要摄像头。最后还是原来的信件样式、两段祝福和 `lh，生日快乐！`。名字只在结尾出现。保留约 4.1 秒的原有逐字展开，文字完整显示后停留在原处。系统减少动态效果开启时直接显示全文。

主画面只提示当前动作。过场旁白删减后，烛光与停顿承担许愿这一幕，星星本身仍带来短祝愿。快速体验入口在页脚。默认静音，手动打开后才创建 Web Audio 上下文。继续使用原有合成八音盒和钢琴，许愿时放轻，烟花时回升，拆信后收回到轻声。切去后台会暂停转场和粒子绘制，关闭正在使用的媒体流并静音。摄像头和麦克风由用户主动授权，只在设备内处理。摄像头模型仅在授权后从本站加载。

## 打开和部署

- `birthday-story.html` 是单文件预览。双击用浏览器打开即可体验点击路线和声音。需要测试摄像头或麦克风时，请使用下述源码包并通过 localhost 或 HTTPS 打开。
- 解压 `birthday-story-source.zip`，在 `index.html` 所在目录启动静态服务器。

  ```sh
  python -m http.server 8000 --bind 127.0.0.1
  ```

  浏览器访问 [本地预览](http://localhost:8000/)。
- 现有站点从 `main` 根目录发布。要复制到独立站点，可将解压后的内容放进新 GitHub 仓库，保留 `.nojekyll` 和 `vendor/` 相对路径，再在该仓库的 Settings → Pages 选发布分支和根目录。项目无需构建命令或后端。

## 修改位置

- `config.js` 中的 `recipient`、`greeting`、`signature` 控制原信件内容。`starWishes` 是三颗星的短祝愿，`audio` 控制默认音量和音轨。选了默认音轨也仍需访客主动开声音。
- `style.css` 开头的颜色变量是界面配色。原蛋糕的点云颜色由 `particles.js` 控制。
- 页面使用代码绘制和本地合成音频，部署包内没有新增图片、字体或音频文件。手势模型和许可证沿用原有的 Apache-2.0 MediaPipe 依赖。

## 实测结果

- 在 Chrome 和 Edge 的移动尺寸窗口走完六幕，并验证信封、彩蛋、静音、重播和快捷入口。分别模拟摄像头被拒、缺设备、超时，以及麦克风被拒。全程点击仍可完成。另用合成摄像头画面跑了原手势模型，用经过滤波的合成音频验证吹烛和媒体流释放。
- 在 Chrome 里直接打开单文件，用 320×568 触控视口测试无 WebGL 和减少动态效果。重复点击已经收下的星星不会再计一次，结尾信件在小屏上可完整显示。默认流程没有外部资源请求。
- 静态首屏文件共 96,310 字节，单文件 HTML 为 96,066 字节。手势模型资源约 24.4 MB，仅在主动授权摄像头后加载。390×844 视口用 Chromium 模拟四倍 CPU 降速时，该测试机上每秒约 41 次粒子画布绘制，显示 9,000 个 WebGL 粒子。这项测量不等同于真机帧率或发热测试。
- 在子路径静态服务测试了资源加载。模拟页面切后台时，粒子绘制及烟花到信封的计时暂停，返回后继续。视觉复核后把快捷入口移到页脚，避免小屏行动按钮另起一行，并删去许愿旁白和其他过场字幕。
- 截图包包含开场、三颗星、聚成蛋糕、许愿、烟花、信封、原祝福、彩蛋八张实际运行截图。当前环境没有 iPhone Safari 或微信真机，设备权限、实际吹气收音和移动端发热未做真机验证。
