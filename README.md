# 生日贺卡更新说明

## 本次更新

- 打开即见星空，可以直接点亮星星。第一次主动开启手势时显示三步指引。摄像头和麦克风各自有授权前说明，与浏览器权限弹窗分开。
- 点星、聚星、点烛、烟花、祝福依次呈现。点击画面或「下一步」按钮可以走完整套，快捷菜单可以直接到指定环节。手势识别、隔空旋转、鼠标拖动和静音偏好延续原来体验。
- 摄像头获准后出现镜像取景框、手部轮廓框和识别进度。设备不可用、权限拒绝或识别超时时，页面继续提供点击操作。可用剪刀手、持续吹气或点击熄灭蜡烛。吹气时同时显示收音量和识别进度。
- 鼠标与单指拖动支持惯性，两指捏合可缩放。键盘可用方向键旋转，Enter 或空格触发当前一步。减少动态效果模式关闭额外惯性和打字动画。
- 粒子保持星空配色，叠加漂浮前景、摇曳烛光和下落余烬。原祝福以逐字动画呈现，收件人仍为 lh。
- 音效和背景音乐默认关闭。可以调节全局音量，选择原创合成的「星光八音盒」或「烛光钢琴」。无需下载音乐文件。
- WebGL 根据设备能力和画面帧间隔调节绘制密度。浏览器缺少 WebGL 时自动使用轻量 Canvas 画面。

## 技术选择

HTML、CSS 和原生 JavaScript，无前端框架、构建步骤、服务端或数据库。WebGL 批量绘制点云，Canvas 2D 绘制烟花和其他叠加效果。Web Audio 在本地合成音乐，并结合现场底噪和短时频谱判定吹气。麦克风分析链的输出增益恒为零，检测期间会暂时停播网页音乐。

手势模型使用 Apache-2.0 授权的 MediaPipe Hands 0.4.1675469240。JavaScript、模型和 WASM 一并放在 `vendor/hands/`，浏览器只从本站加载，摄像头授权后才下载。许可证、出处和文件校验值都随源码附带。

摄像头帧和麦克风音频只在内存中处理，程序没有保存或上传入口。媒体流在结束、取消或切出页面时关闭。页面用内容安全策略限制请求来源。浏览器本地存储中唯一由本页写入的是已经看过指引的开关。

## 本地运行

解压源码包，在有 `index.html` 的目录执行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

使用系统浏览器打开 [本地页面](http://localhost:8000/)。手势和吹气需要浏览器权限和安全上下文。双击打开单文件预览适合体验点击模式和音效。

## GitHub Pages 部署

把包内的 `index.html`、各 `.js` 文件、`style.css`、`vendor/` 和 `.nojekyll` 原样放到 Pages 的发布分支根目录。现有项目使用 `main` 的根目录作为发布源。保留目录结构，等 Pages 部署完成后直接打开 HTTPS 地址即可。

如果微信内置浏览器没有开放媒体权限，仍可直接点击体验。要使用手势或吹气，可选择在系统浏览器打开。播放声音同样由页面内的开关控制，首次打开是静音。

## 定制文案

`config.js` 中的 `recipient`、`greeting` 和 `signature` 分别对应收件人、祝福段落及署名。姓名只出现在结尾。音序在 `sound.js` 内，可直接修改。
